the COP31 collapse in Antalya, a Russian warship sunk off Benghazi,
the Banten factory fire, Iran's daily power cuts, and the Gukesh vs
Sindarov World Chess Championship opener.

`main.ts` copies the finished 1024×1024 `entry.png` to
`$MAKEFUN_OUTPUT_DIR` (default `/output`). No network, no dependencies.
